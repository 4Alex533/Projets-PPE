**Projet 1 — Poste de travail pour un cabinet comptable**


***1. Installation du système d'exploitation à partir d'un support d'installation***

- Vous trouverez le système d'exploitation sur VMware Workstation (Les deux carrés orange et bleu dans la barre des tâches)

- Pour ouvrir le système d'exploitation, cliquez deux fois sur 'Windows 11', puis cliquez sur 'Power on this virtual machine'

- Le mot de passe pour ouvrir Windows est: 'Win83421'

![2026-09-14_09h00_50](https://hackmd.io/_uploads/BkUhGSBtzl.png)

***2. Créer un compte administrateur local + un compte utilisateur standard pour la collaboratrice***

**- Pour créer un compte administrateur et un compte utilisateur standard, voici les étapes à suivre:**

- Appuyer sur l'icone 'Windows' en bas à gauche, puis aller dans les paramètres ---> Comptes ---> Autres utilisateurs

![2026-09-14_11h53_31](https://hackmd.io/_uploads/Sym2EUBKzx.png)

- Cliquer sur 'Je ne dispose pas des informations de connexion de cette personne' puis sur 'Ajouter un utilisateur sans compte Microsoft'

![2026-09-14_11h53_54](https://hackmd.io/_uploads/ryI2NLrYfl.png)

![2026-09-14_11h54_17](https://hackmd.io/_uploads/ryA2NUrKzg.png)

- Créer un nouvel utilisateur en rentrant les informations demandées

![2026-09-14_11h56_06](https://hackmd.io/_uploads/SJ7aELrtGl.png)

- Une fois le compte créé, cliquer sur 'Modifier le type de compte' et selectionner 'administrateur' ou 'utilisateur'

![2026-09-14_13h09_03](https://hackmd.io/_uploads/SJmlvIBYGg.png)

- Sur l'image si dessous vous pouvez observez où vous pouvez trouver le compte administrateur et le compte utilisateur

![2026-09-14_11h59_07](https://hackmd.io/_uploads/BkIkrLrFzx.png)

***3. Configurer le réseau (adresse IP, nom de la machine, groupe de travail)***


**- Voici les étapes à suivre pour configurer une adresse IP:**

- Cliquer sur 'Windows' en bas à gauche

![2026-09-14_13h28_27](https://hackmd.io/_uploads/ByiGxDBtzl.png)

- Sélectionner 'Paramètres' ---> 'Réseau et Internet' ---> 'Ethernet' ---> 'Attribution IP' ---> 'Modifier' ---> 'Automatique (DHCP)'

![2026-09-14_13h29_16](https://hackmd.io/_uploads/H1W4ePBKfx.png)

**- Voici les étapes à suivre pour modifier le nom de la machine**

- Aller dans 'Paramètre' ---> 'Système' ---> 'Information système'

![2026-09-14_13h29_49](https://hackmd.io/_uploads/ByqgZvBKMx.png)

- Cliquer sur 'Renommer ce PC'

![2026-09-14_13h30_15](https://hackmd.io/_uploads/HJfNWDrtfl.png)

- Écrire le nom qui convient

![2026-09-14_13h31_17](https://hackmd.io/_uploads/rJnBZvStMl.png)

- Redémarrer

![2026-09-14_13h31_42](https://hackmd.io/_uploads/ByhI-PHKGg.png)

**- Voici les étapes pour configurer le groupe de travail**

- Appuyer sur 'Windows + R', taper 'sysdm.cpl' ---> Enter

- Cliquer sur l'onglet 'Nom de l'ordinateur' puis sur 'Modifier'

![2026-09-14_13h36_53](https://hackmd.io/_uploads/ry6QQPrtzl.png)

- Dans 'Groupe de travail' entrer le nom du groupe, puis cliquer sur 'Ok'

![2026-09-14_13h38_27](https://hackmd.io/_uploads/B1EwmwSFfe.png)

- Cliquer sur 'Redémarrer'

![2026-09-14_13h39_00](https://hackmd.io/_uploads/S1x2QvStGx.png)

***4. Installer les logiciels métier de base demandés ( Microsoft Word, lecteur PDF, navigateur***

**- Installation de Microsoft Word**

- Pour installer Word, il faut d'abord installer Microsoft 365

![2026-09-14_14h39_15](https://hackmd.io/_uploads/S1ufCwrFGx.png)

- Quand Microsoft 365 est installer, cliquer sur l'icone 'Windows' et cliquer sur 'Word' si il apparait directement, sinon cliquer sur 'Afficher tout' et chercher 'Word'

![2026-09-14_14h50_42](https://hackmd.io/_uploads/Syte1_rtGl.png)

![2026-09-14_14h51_12](https://hackmd.io/_uploads/rkLWJurYGg.png)

**- Installation de lecteur PDF**

- Pour installer l'application 'Lecteur PDF' il faut aller sur 'Microsoft Store' et taper dans la barre de recherche 'lecteur PDF' et cliquer sur 'Obtenir'

![2026-09-14_14h58_45](https://hackmd.io/_uploads/ByUWg_BYMg.png)

**- Installation d'un navigateur (Google chrome)**

Dans la barre de recherche, taper 'Google chrome' puis 'Enter' et finalement, cliquer sur 'Installer Google chrome'

![2026-09-14_15h01_44](https://hackmd.io/_uploads/B1GUbdrFzl.png)

- Sur cette page, cliquer sur le téléchargements

![2026-09-14_15h02_36](https://hackmd.io/_uploads/ByzxGOrYzx.png)

- Autoriser les modifications de l'ordinateur

![2026-09-14_15h02_54](https://hackmd.io/_uploads/H17WMOStzl.png)

- Attendre que 'Google chrome' s'ouvre automatiquement

![2026-09-14_15h05_53](https://hackmd.io/_uploads/HyRIGuHYfe.png)

***5. Installation d'une imprimente réseau partagée***

- Cliquer sur l'icone 'Windows', puis aller dans 'Paramètres' ---> 'Bluetooth et appareils' ---> 'Imprimantes et scanners'

![2026-09-14_15h12_48](https://hackmd.io/_uploads/Hy1TIOrYMe.png)

- Sélectionner l'imprimente et cliquer sur 'Propriétés de l'imprimente

![2026-09-14_15h17_21](https://hackmd.io/_uploads/B1nGPOHYfg.png)

- Cliquer sur l'onglet 'Partage', cliquer sur 'Modifier les options de partage' puis sur 'Partager cette imprimante'

![2026-09-14_15h17_43](https://hackmd.io/_uploads/H1s5v_SYzg.png)

- Donner un nom à l'imprimante

![2026-09-14_15h19_49](https://hackmd.io/_uploads/B1Jl_uSKzl.png)

- Ensuite revenir sur 'Imprimantes et scanners'

![2026-09-14_15h36_53](https://hackmd.io/_uploads/r1WqddHYMx.png)

- Cliquer sur 'Ajouter un appareil'

![2026-09-14_15h22_51](https://hackmd.io/_uploads/r1t6_dSFGg.png)

- Cliquer sur 'ajouter un nouvel appareil manuellement'

![2026-09-14_15h23_08](https://hackmd.io/_uploads/H1_xKOrKzg.png)

- Cliquer sur 'sélectionner une imprimante partagée par nom' et écrire comme l'exemple donné en bas mais avec le nom de l'imprimante

![2026-09-14_15h24_32](https://hackmd.io/_uploads/B18YYOHFfl.png)

- Attendre la fin de l'installation de l'imprimante

***6. Vérifier que les mises à jour Windows sont activées et à jour***

- Pour vérifier si il y a des mises à jour à faire il faut, dans la barre des tâches, cliquer sur 'Windows' ---> 'Paramètres' ---> 'Windows Update' et si il y a des mises à jour, cliquer sur 'Tout télécharger et installer' et attendre que le chargement se termine.

![2026-09-15_08h58_00](https://hackmd.io/_uploads/rkbYpwIFzx.png)

![2026-09-15_09h00_57](https://hackmd.io/_uploads/SJ9F6DUtGg.png)

![2026-09-15_09h04_22](https://hackmd.io/_uploads/HkByMOUtfx.png)

***7. Activer un antivirus et le pare-feu, documenter la configuration***

**- Activer l'antivirus**

- Dans la barre des tâches, ouvrir 'Démarrer' ---> 'Paramètres' ---> 'Confidentialité et sécurité'

![2026-09-15_09h35_45](https://hackmd.io/_uploads/S1tZwOLtzg.png)

- cliquer sur 'Sécurité Windows' ---> 'Protection contre les virus et menaces'

![2026-09-15_09h36_02](https://hackmd.io/_uploads/ryZvDu8Fzl.png)

- Cliquer sur 'Gérer les paramètres'

![2026-09-15_09h36_34](https://hackmd.io/_uploads/S1KRDOUYfx.png)

- Activer 'Protection en temps réel'

![2026-09-15_09h36_58](https://hackmd.io/_uploads/H16ZddUYMl.png)

**- Activer le pare-feu**

- Dans 'Sécurité Windows', cliquer sur 'Pare-feu et protection réseau'

![2026-09-15_09h36_02](https://hackmd.io/_uploads/ryZvDu8Fzl.png)

- Cliquer sur 'Réseau de domaine', 'Réseau privé' et 'Réseau public', 

![2026-09-15_09h38_42](https://hackmd.io/_uploads/SJikFuItfl.png)

- Vérifier que 'Pare-feu Microsoft Defender' est activer pour tous
